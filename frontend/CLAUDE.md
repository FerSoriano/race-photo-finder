# Frontend rules

**The stack is not chosen yet. Do not add code, dependencies, or config here.**

Read `README.md` in this folder for the candidate stacks and the criteria that
should decide between them. Choosing is the user's call -- if a task seems to
require frontend work, ask which stack to use before creating anything.

Until then, the backend is consumed with plain HTTP calls; `docs/ARCHITECTURE.md`
documents the endpoints.

Agents do not commit or push. See the Git section in the root `CLAUDE.md`.
